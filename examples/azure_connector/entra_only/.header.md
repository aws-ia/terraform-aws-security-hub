# Azure connector: Entra ID only

The first half of a split deployment, for when a directory administrator and an Azure administrator are different people. A Global Administrator, or a Privileged Role Administrator who is also an Application Administrator or Cloud Application Administrator, applies this example; it needs no subscription access. Pass its outputs, and the same `lead_aws_account_id` and `onboarded_accounts`, to the [`arm_only`](../arm_only) example.
