# GCP connector: complete

Onboards a GCP organization for AWS Config and Amazon Inspector, including Compute Engine VM scanning, in one Terraform state. This example turns Amazon Inspector on for every entry unless the entry sets `enable_inspector = false`; the module's own default is `false`. The identity that runs it needs the permissions of the [`gcp_connector`](../../../modules/gcp_connector) module. Applying with `target_project_ids` also needs the `gcloud` CLI on `PATH`. Set `pubsub_kms_key_name` to encrypt the connector topics with your own Cloud KMS key, and `manage_audit_config = false` when another configuration owns the organization audit configuration.

```shell
gcloud auth application-default login
terraform init
terraform apply \
  -var organization_id=<organization id> \
  -var project_id=<management project id> \
  -var 'target_project_ids=["<vm project id>"]' \
  -var 'onboarded_accounts=[{aws_account_id="123456789012",aws_region="us-east-1",issuer_url="https://<id>.tokens.sts.global.api.aws"}]'
```

Use `per_account_connector_inputs` from the outputs when you create the connector in AWS.
